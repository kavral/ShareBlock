# ShareBlock Prototype

Fractional Commercial Real Estate Tokenization Platform.

## Overview
This prototype implements the core smart contract logic for ShareBlock (AIFC SPV fractional real estate tokenization platform), handling token minting, role-based access control, and proportional rental dividend distributions.
